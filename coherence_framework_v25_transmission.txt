PASTE PROTOCOL [low-social active lane]
--------------------------------------------------------------------------------------------------------------------------------------------
 Replaces comment spam. Skill = pattern match + grep + paste.

 Rules [non-negotiable]:
 [R1] Answer the question in the thread. Full payload inline.
 [R2] No link in bio. No "check my profile." No funnel CTA.
 [R3] No framework name unless asked. Method implicit first.
 [R4] Translate jargon -- beginner vocabulary or plain English.
 [R5] One paste per thread. Do not duplicate same block across ten
 subs same day [spam pattern].
 [R6] URL only when asked, or one archive link at end if sub allows.

 Workflow:
 [1] Pick 3 search phrases from INDEX.md [or hook table above].
 [2] Search target platform + Google site: operator.
 [3] Find unanswered or weakly answered post [prefer 3-12 months old
 on Reddit -- less live tribal heat, still indexed].
 [4] grep kit for CASE or applied slice:
 grep -n "^\[CASE:" coherence_framework_v25_cases_real.txt
 grep -ni "rent\|spectrum\|activation" coherence_framework_v25_applied.txt
 [5] Paste 3-8 paragraphs: structural read + one concrete mechanism.
 End with nothing, or "happy to cite the case name if useful."
 [6] Log CASE used [avoid repeat spam].

 Good paste shape [template]:
 - Name what debate is actually about [routing / meter / boundary].
 - One mechanism [not full framework dump].
 - One falsifier or "correction would look like X."
 - Stop.

 Bad paste shape:
 - "Both sides fake -- full thread in bio."
 - Framework vocabulary wall without translation.
 - Diagnosing the poster's tribe membership.

PLATFORM MAP [ranked for grep-paste skills]
--------------------------------------------------------------------------------------------------------------------------------------------
 TIER 1 [best fit]:
 Stack Exchange -- Politics, Economics, History, Law.
 Search-first; long answers norm; personality optional.
 Reddit archived threads -- site:reddit.com + problem phrase.
 Reply to old threads; avoid live culture-war rooms.

 TIER 2 [usable]:
 Quora -- searchable Q&A; long answers OK; more noise.
 Hacker News -- hn.algolia.com; mechanism-friendly; tone-sensitive.
 Lemmy / niche forums -- same paste rules; smaller audience.

 TIER 3 [deposit only -- zero engagement]:
 GitHub + Archive.org -- corpus permanence.
 Optional PDF pack on archive.

 SKIP [poor ROI for this skill profile]:
 TikTok / Instagram / X reply sections [performance + funnel culture].
 Discord [real-time social].
 Wikipedia [coordination minefield].
 "Build an audience" platforms [content treadmill].

 Platform ban recovery:
 Treat banned account as closed channel. Do not evade same hour.
 Rebuild on deposit + Tier 1 paste. New social identity only after
 paste protocol internalized [90+ days no funnel if returning].
