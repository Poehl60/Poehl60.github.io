ORDER TOWARD TRUTH [named distinction -- v25]
--------------------------------------------------------------------------------------------------------------------------------------------
 Order is good only as orientation toward truth [legible, correctable structure]. Order that serves a
 person, formation, or nation is loyalty architecture wearing a rulebook -- not truth contact.
 Telos test:
 Beneficiary-order: rules fire to protect THIS actor or THIS unit [stability, punishment of threats
 to us, cohesion, loyalty reward]. Legitimacy surface / imposed axis / partial state religion class.
 Truth-order: rules fire to make structure legible and correctable -- CAUSAL LEGIBILITY, MEASUREMENT
 INTEGRITY, behavioral record over stated position. Oriented toward TRUTH AXIS contact via four
 conditions [tests not badges].
 THREE ORDER TYPES [political psychology routing]:
 GENERATIVE ORDER: order toward truth + correction + surplus flow outward. Rules hold tension
 routing traceable; break captured order when contact blocks. Material surplus legitimate only
 here -- landing, not loyalty reward.
 PUNITIVE ORDER: hostility through rule-enforcement mask [tradition, obedience, punish deviance].
 Punitive costume serving the bridger, not truth or fair distribution -- L/R jersey irrelevant.
 Optional psych illustration [grep theory ORDER TRUTH REFERENCE BANK -- not kit finding].
 COMPLIANCE ORDER: hostility through moral/conformance mask [cancellation, virtue enforcement,
 "our side" policing]. Stated anti-hierarchy can still be beneficiary-order. Mirror on compliance
 mask -- L/R jersey irrelevant; psych adjacency optional, not load-bearing.
 Distinctions load-bearing:
 ROUTING [who gets surplus] ≠ ORDER TYPE ≠ CORRECTION [break/fix when order blocks contact].
 **THREE ORDER TYPES -- TESTS [one named row each; costume is not evidence -- 2026-11-05]:**
 GENERATIVE: name the surplus, name who receives it **outside the issuing unit**, name the correction
 path that fired **against the issuer at least once** [unfired = untested, not clean].
 PUNITIVE: name the rule broken + name who benefits from the punishment; if the punishment serves
 distribution or truth-contact instead, not punitive.
 COMPLIANCE: name the conformance demand + name who gains from the policing; stated anti-hierarchy
 is **not** a pass -- the beneficiary test decides.
 **Overlap read:** punitive + compliance are **mask variants of one hostility routing** -- split by
 which register is enforced [force/threat vs moral standing], never by jersey.
 Marx praxis read [11th Thesis]: change the world = doing over yap; not order for a class beneficiary.
 **MIXED-ROW FIX [lanes, not rows -- analyst 2026-11-05]:** score per **domain / lane**, not whole
 row. One actor can run truth-order on a measurement lane and beneficiary-order on a distribution
 lane in the same quarter -- that is normal, not a contradiction. Report **band per lane + one
 dominant vector** [which lane sets the budget and controls the exit]. Whole-row single verdict is
 reserved for rows with **one** routing lane only.
 **Falsification [loss permitted -- analyst 2026-11-05]:** beneficiary-order consistently produces
 higher CAUSAL LEGIBILITY and correction access than truth-order on the same substrate across
 repeated rows. **A single losing row does not falsify** -- truth-order that pays and loses on one
 named row is expected, not disconfirmed; one failed instance is **never** a group verdict ["the
 formation lost, so write off everyone in it" is not a test result]. Falsifier fires only when
 truth-order cannot name the priced sacrifice it made on **any** row.
